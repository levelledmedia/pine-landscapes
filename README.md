# Pine Landscapes

An Astro site, generated with WebGen Studio and graduated to this standalone repo — it no longer depends on Studio or any other part of that monorepo. Edit it directly from here on (by hand, or with a coding agent like Claude Code).

Live at https://levelledmedia.github.io/pine-landscapes/ — every push to the default branch rebuilds and redeploys it automatically (see `.github/workflows/deploy.yml`).

## Getting started

```bash
npm install
npm run dev
```

`npm run build` produces a static, production-ready `dist/`.
